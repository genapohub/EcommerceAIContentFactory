# 电商AI内容工厂 MVP 规格 v2.0

2026-09-17。依据：本项目四份生成能力调研、用户已明确的商品照片与参考视频两条流程。状态：代码已落地，离线工程测试通过；真实模型与10 SKU业务验收待执行。最终后端修复需在当前服务重启后加载。

## 1. 产品定义

为抖音/视频号中小商家，把实拍商品照片变成主图、逐屏详情图片与介绍视频，把自有商品素材结合参考视频重制成片。基础商品字段全部可选，真实生成任务按必要媒体逐项校验。

## 2. MVP范围与优先级

| 优先级 | 功能 | 可交付结果 |
| --- | --- | --- |
| P0 | 商品项目、实拍照片、参考视频文件/链接、可选基础资料 | 服务端持久化，重启恢复 |
| P0 | 国内模型配置 | 百炼万相/Qwen、Vidu真实适配；密钥不回显、不入浏览器存储 |
| P0 | 文生图、商品图生图 | 真实图片文件、预览、下载、重生成 |
| P0 | 分屏详情 | 6个可编辑模块，真实AI配图与可控中文排版，单屏/长图/ZIP导出 |
| P0 | 图生介绍视频 | 万相真实异步任务、MP4结果，支持不同脚本变体 |
| P0 | 参考视频复刻 | Vidu真实任务，参考媒体+商品图输入，成片下载 |
| P0 | 任务管理 | 排队、生成中、部分成功、失败、待核对、完成；费用预估、幂等提交、单项重试 |
| P1 | 商品/视频AI理解 | Qwen结构化分析，来源标记、卖点及镜头编辑、无依据事实不自动确认 |
| P1 | 内容检查与导出 | 风险词提示、同一商品资料驱动图片/脚本、Markdown/CSV/媒体ZIP |

业务目标：10个真实SKU验证，五类各2个。输出主图3张、商详6屏、介绍视频和复刻视频各1条；采纳率与单套成本据实记录，不承诺爆款或固定生成时延。

## 3. 边界

首版部署为本机单用户工作台，由本机服务提供网页和API。公网多人SaaS、支付订阅、店铺授权、自动投流、自动发布不纳入本轮。链接先支持公网可下载视频及页面公开媒体，不承诺绕过登录、反爬或全网平台。用户提供文件可完成同一任务。

## 4. 技术契约

保留原生HTML/CSS/JS体验和旧方案引擎；新增Node.js 24后端、SQLite、本机素材目录、官方供应商适配。Express/Multer/Sharp/Zod/Lucide/Archiver版本锁在package.json及pnpm-lock.yaml。图片排版用Sharp；视频媒体探测/裁切/必要转码用FFmpeg。界面不设置“本地AI引擎”。

## 5. API

前缀`/api/v1`，服务健康`/healthz`。项目、素材、配置、报价、任务、分析、文档及媒体导出。所有写入需要本机会话令牌和同源校验；文件路径、外部URL和模型参数服务端校验。机器契约见`03-技术文档/电商AI内容工厂_API_v2.0.yaml`。

## 6. 数据

SQLite持久化projects、assets、jobs、settings。项目保存当前资料与可编辑方案，任务保存提交时的不可变输入快照、供应商任务ID和输出资产。密钥只读取环境变量或服务器进程内存；配置的非敏感字段持久化。重启时有供应商任务ID的任务可继续查询；提交结果不确定时禁止自动重新付费提交。

## 7. 页面

三处导航：内容生产、任务记录、国内模型。内容生产包括商品内容/参考复刻两个任务，左侧素材与可选字段，右侧主图/详情/视频预览。方案与文案编辑在次级视图，主工作区直接呈现媒体。

## 8. 设计

白色与浅灰工具界面，绿色主操作、黄色待处理、红色失败、蓝色参考。紧凑表单、稳定预览比例、8px以内圆角。Lucide统一图标、键盘可达、375px移动布局、Reduced Motion。样式Token定义于设计文件与前端令牌文件。

## 9. 验收标准

- 当基础信息为空时，可以保存项目和编辑草稿，不出现必填拦截；缺商品图片只阻断依赖图片的任务。
- 当用户上传图片/视频时，服务检查真实文件类型、大小和媒体可读性，重启后仍可预览。
- 当未配置密钥时，提交模型任务得到明确缺配置提示，不生成假成功结果。
- 当选择多个产物时，显示逐项预估并分别排队，一项失败不覆盖已有成功文件。
- 当供应商已接单时，持久化任务ID；重复点击同一个提交不重复收费；查询超时保留任务供核对。
- 当生成成功时，先下载并核验文件，再标记完成；媒体文件可预览、下载，临时外链失效不丢失本地结果。
- 当修改商详文案时，可以重新排版已有图片，不必重新调用模型；可导出逐屏图与合成长图。
- 当参考链接无法解析时，给出上传文件的明确路径；不把保存URL称为视频分析。
- 当分析视频时，结果包含真实来源的时间段、钩子、痛点、证明和CTA；未经分析的结构仅标记为草稿。
- 当输入恶意HTML、路径穿越、内网URL或跨站请求时，不执行脚本、不读取任意本地文件、不访问内网、不触发生成。

## 10. 约束

实际账号权限、余额、模型可用性与内容审核由供应商决定。真实付费调用由用户在本机配置后执行。测试替身只用于测试进程，不可在产品内冒充模型。生成成功、效果合格、业务采纳和可生产部署分别验收。

## 11. 已知问题

Vidu参考视频请求体20MB、临时结果有效期短；大文件需压缩或公开媒体URL。Vidu图片参数必传/可选描述冲突，产品复刻统一要求自有商品图。万相同步生图与异步视频响应不同，错误不能共用成功解析。中文长图应独立排版，不能依赖模型写准规格文字。

## 12. 验证与交付

节点语法检查、核心业务和供应商契约测试、HTTP端到端测试、重启恢复与安全错误路径、桌面/手机浏览器验收。运行说明、部署说明、测试报告和账号联调未决项归档。真实模型未联调时明确记录，不将协议测试包装成真实生成通过。
