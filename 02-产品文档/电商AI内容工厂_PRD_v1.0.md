# 电商AI内容工厂_PRD_v1.0

## 结论

本项目首版定位为抖音/视频号中小商家的商品转化内容工作台。核心目标是把一个 SKU 快速转成“1 套商品详情页模块 + 3 条短视频爆款复制方案 + 发布前检查”，先验证内容策略和脚本生产价值，不把真实视频渲染作为首版强依赖。

## 背景/目标

中小商家常见问题不是没有商品，而是不会稳定表达商品价值：详情页写一套、短视频又写一套，卖点不一致，爆款参考也只能靠人工模仿。MVP 要解决三个问题：

| 问题 | 影响 | MVP 解法 |
| --- | --- | --- |
| 卖点提炼弱 | 商品页和短视频转化表达散 | 生成商品转化档案和卖点库 |
| 爆款不会拆 | 只能照搬文案，风险高 | 拆结构、复刻策略，不复制内容 |
| 内容产能低 | 单 SKU 制作周期长 | 联动生成详情页和短视频方案 |

北极星指标：每个商品从录入到导出内容方案控制在 10 分钟内。

## 方案

### 核心用户

- 抖音/视频号中小商家
- 单店卖家
- 2-5 人小运营团队

### 核心流程

1. 新建商品项目，录入商品名称、类目、价格、人群、规格、卖点和素材。
2. 上传或粘贴爆款参考。
3. 生成商品转化档案和爆款结构卡。
4. 同步生成详情页模块和 3 条短视频脚本。
5. 进行发布前风险检查。
6. 导出 Markdown 方案。

### MVP 功能

| 模块 | 功能 | 验收标准 |
| --- | --- | --- |
| 商品资产解析 | 提炼类目、人群、核心卖点、场景、顾虑 | 至少输出 3 个核心卖点 |
| 爆款拆解 | 识别钩子、节奏、复刻策略 | 至少输出钩子、痛点、证明、CTA |
| 详情页生成 | 输出固定商详页模块 | 至少包含首屏、卖点、场景、证明、对比、FAQ、下单理由 |
| 短视频复制 | 输出 3 条不同结构脚本 | 每条包含标题、钩子、口播、镜头、字幕、CTA |
| 一致性校验 | 检查卖点一致、风险词、素材缺口 | 输出发布前检查清单 |
| 生成记录 | 留存每次生成的商品方案 | 自动记录商品、时间、详情页模块数、短视频数、风险词数量，并支持载入历史结果 |
| 国内模型配置 | 配置火山、阿里云、百度、腾讯、智谱或自有国内模型网关 | 不出现非国内通用入口 |

## 执行

首版采用纯前端静态实现，降低交付成本，优先验证产品体验。内容生产区生成后优先展示商品主图、介绍视频和分屏详情页三类交付物预览；后续接入国内图文模型、视频模型、视频理解、自动成片和投放数据。代码统一收拢在 `06-项目编码/EcommerceAIContentFactory/`，便于后续迁移为完整前端工程。每次生成结果保存到浏览器本地记录，方便运营对比不同 SKU 和不同爆款参考。

## 验收

- 用服饰、美妆、食品、家居、3C 五类样例跑通。
- 每个样例稳定输出 1 套详情页模块和 3 条短视频方案。
- 风险词命中后能进入发布前检查。
- 内容导出为 Markdown，可被运营继续修改。
