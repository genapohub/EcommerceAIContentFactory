# 电商AI内容工厂：调研结论与验证清单 v1.0

调研日期：2026-09-17。范围：商品主图、分屏详情页、介绍视频、参考爆款视频重制。本文是调研建议，不代表已经接入或完成真实生成。

## 摘要

这条产品方向已有直接竞品。PicCopilot 的公开工作台同时展示详情页和爆款复刻入口；Topview 明确展示参考视频分析与重制；国内生成模型可以作为自建工作台的底层服务。建议按“电商图片与商详生产”和“参考视频重制”两条业务流程组织产品，模型参数放在配置层。

现有工作台仍是前端方案生成与预览。此次检查 `应用.js` 的生成入口调用 `ContentEngine.generatePlan`；本次未修改应用、未执行模型付费调用、未产出图片或视频成品。

### 汇总选型建议

| 需求 | 首轮对标/验证对象 | 已有证据与选择理由 |
| --- | --- | --- |
| 整套商品详情页 | 美图设计室、稿定AI、PicCopilot | 三家均有整套商详的官方描述；长图、分层编辑、逐屏导出需要分项验证 |
| 自带参考视频重制 | 美图设计室、Creatify、Topview | 官方描述参考视频输入；Creatify另有专用Ad Clone API。美图此次核实为Designkit公开英文站，国内功能是否同步需另查 |
| 国内图片与介绍视频后端 | 万相优先作为成本基线，Seedream/Seedance作对照 | 已取得文生图、图生图、图生视频及参考/编辑的官方接口参数与价格口径 |
| 国内整片复刻后端 | Vidu一键复刻优先列入专项试验 | 公开接口直接接受参考视频与商品图，更贴近用户的整片输入需求；效果和编辑粒度尚未实测 |
| 人物动作与原片编辑 | 可灵专项对照 | 官方独立动作控制、视频参考和原片编辑契约；不将人物动作能力泛化为任意商品替换 |

Vidu官方文档：[一键视频复刻](https://platform.vidu.cn/docs/one-click-trending-replicate)。主控另外通过HTTP读取核实 `POST https://api.vidu.cn/ent/v2/trending-replicate`、`video_url`、`images`、5–180秒参考片与1–7张参考图。该URL指可访问的视频媒体地址，不代表直接支持抖音或视频号分享页面。文档的图片必传标记与“可选”说明不一致，接入前需澄清。

推荐先验证“万相图像/图生视频 + Vidu整片复刻”这条最短业务路径，同时保留按镜头生成的可控路径。架构报告中的万相、火山、可灵评分只比较三套基础模型栈，不包含Vidu成片工作流的效果排名；最终选择以同一批SKU实测为准。

费用上，万相文生图的公开北京刊例为0.20元/成功输出张，万相2.6 i2v-flash无声720P为0.15元/成功输出秒。它们不是整套商详或成片的总成本。Vidu复刻公开720P为0.50元/计费秒，但计费秒数取输入还是输出尚未核实，不据此承诺整片固定价。完整出处、地域和模型限制见国内接入报告。

## 证据口径

| 等级 | 本次如何使用 | 不能推出什么 |
| --- | --- | --- |
| 官方产品页 | 核实产品定位、声明的输入输出 | 不证明实际生成质量、稳定性或转化收益 |
| 公开界面观察 | 浏览器查看入口、控件、示例与导航 | 未登录生成，不算完成生产闭环 |
| 官方接口文档 | 核实参数、模型、调用方式与限制 | 不等于当前账号已开通或完成联调 |
| 真实样本测试 | 本轮未执行 | 不给实测成功率、耗时、成本或销量提升结论 |

官网宣称的“1分钟”“爆款”“完美继承”“提升转化”均不能直接作为我们的承诺。页面未找到某项功能，统一记为“本次未核实”，不据此断言产品不支持。

## 四类生成能力如何对应需求

| 能力 | 在电商中的用途 | 推荐边界 |
| --- | --- | --- |
| 文生图 | 场景背景、创意草图、分屏配图 | 没有实物参考时不承诺还原真实SKU；文字与规格来自商品档案 |
| 图生图 | 实拍商品生成主图、换背景、卖点图 | 优先保留真实商品主体；检查颜色、Logo、包装字、部件数量 |
| 图生视频 | 商品展示、场景使用、短镜头 | 先做短镜头，再配音、字幕与合成；单张照片无法证实背面和隐藏结构 |
| 爆款视频生视频 | 参考结构、动作、运镜与节奏，为自己的商品重制 | 按结构复刻、动作参考、局部编辑分别定义任务，不承诺任意视频一键无损换品 |

“分屏详情页”还需要结构化文案、统一模板、逐屏编辑及图片导出。一个文生图模型本身不等于完整商详生成系统。

## 最直接的对标证据

### PicCopilot：重点参考商品资产生产

- [公开工作台](https://www.piccopilot.com/create)：浏览器观察到并列的“爆款视频复刻”和“详情页工具”，前者文案为“上传商品图+选择参考视频，一键生成专属爆款视频”。
- [爆款视频复刻功能页](https://www.piccopilot.com/zh/tools/viral-video-maker)：官方流程为商品图、视频模板、带音乐视频；标注约12秒。
- [爆款视频克隆功能页](https://www.piccopilot.com/zh/tools/automated-viral-video-clone)：明确选择类目模板、上传1–3张商品图、自定义卖点与标志后生成。
- [详情页帮助文档](https://www.piccopilot.com/zh/help/tool_course/product-listing-page-tool-zh)：官方描述商品图、基础信息、模板，生成图片、文案和排版，支持内置编辑器和高分辨率素材下载。
- 边界：尚未核实任意用户视频链接或文件导入、逐屏图片打包格式和这两项业务的公开API。详情页帮助文档存在截图占位文字，不能当作生成效果样本。

### Topview：重点参考自带视频的重制流程

- [官网](https://www.topview.ai/)明确写“Upload a reference video”，分析“style, rhythm, shot structure, camera language, and hooks”。
- 官网案例将“Reuse this video's script structure”“Replicate video hook for my product”与商品URL生成广告分开。
- 公开工作区可见图片、视频、音频上传，以及 Video Clone、URL to Video、Product Ads 等不同任务入口；未进行登录、上传或生成。
- [API入口](https://www.topview.ai/openapi)的存在不能直接证明“参考视频重制完整业务”已开放API，需逐接口核实。
- 该产品仅作工作流对标；不因此更改本项目仅接入国内模型的约束。

其余竞品、接口与交互建议见同批研究文档。以上两项是主控直接浏览核实的证据，不是购买推荐或效果排名。

## 本项目建议工作流

### 商品图生产

1. 拍摄或上传一张商品图即可开始；名称、卖点、价格等保持选填。
2. AI识别外观与候选卖点；没有依据的材质、容量、功效、认证不自动补成事实。
3. 用户勾选主图、分屏商详、介绍视频，分别显示任务和预估消耗。
4. 主图先确定商品外观，分屏复用已确认的素材和卖点；规格文字通过可编辑排版层输出。
5. 介绍视频按镜头生成并合成；成功的图片先交付，某个视频失败不阻塞全部结果。
6. 交付PNG/JPG主图、逐屏图片与长图、可播放MP4，并保留可编辑文案和分镜。

### 爆款参考重制

1. 输入参考视频文件，或提供支持解析的视频链接；链接无法获取时给出文件上传入口，不把仅保存URL当作解析成功。
2. 加入自己的商品图片或视频素材，选定要复用的结构、节奏或动作。
3. 对参考视频做切镜、语音转写、字幕识别及画面理解，形成带时间码的镜头表。
4. 用户确认钩子、产品露出、卖点和镜头，再生成自有商品的关键帧及短镜头。
5. 配音、字幕、音乐和镜头合成后交付成片；可独立重做某个镜头。
6. 核查商品外观、文字、音画同步以及参考素材使用权限；“复刻”不承诺复刻销量。

可先做“保留叙事结构并重新生成镜头”。原视频直接局部换商品，尤其手持、遮挡、反光和快速运动场景，单列为进阶能力进行样本验证。

## 验证方案

以下均为建议测试规模与门槛，不是本次已经取得的成绩。

本节是业务闭环验收包（10 SKU、90张图、20条视频）。技术报告另外列了三供应商的对照实验（180张图、180个候选镜头、30条合成视频），用于模型筛选；两者是不同阶段的建议，不是重复计算的已执行测试或已批准预算。

- 10个真实SKU：服饰、美妆、食品、家居、3C各2个；测试自有或获授权的图片与视频。
- 每个SKU：主图3张、商详6屏、15秒介绍视频1条、参考重制视频1条，共30张主图、60屏商详、20条视频。
- 图像必检：商品颜色/结构/品牌与规格一致，文案准确、字体清晰；任何编造认证或关键规格错误均退回。
- 视频必检：产品不变形、不串品，字幕无截断，配音可听，镜头无黑屏，实际MP4可下载播放。
- 参考重制必检：拆解至少包含钩子、卖点、证明、CTA；保留用户选择的节奏与结构，使用自己的商品素材。
- 链接测试：支持平台逐个列出成功与失败样本；失效链接、登录页、不可访问链接与错误文件格式均要有可操作反馈。
- 成本记录：首次生成、重试、报废、配音、合成、存储分别记账；以“单套被采纳成品成本”作比较，不只比较一次API报价。
- 建议继续投入条件：至少8/10 SKU完成全部交付，图片采纳率达到60%，视频采纳率达到50%，商品关键事实错误为0；由10个样本再校准门槛和价格。

原先“10分钟生成内容方案”的目标不能平移成“10分钟完成所有高清视频”。分别记录交互耗时、排队耗时、生成耗时和人工修改耗时，再制定服务承诺。

## 待验证清单

| 问题 | 关闭条件 |
| --- | --- |
| 选哪个国内模型组合 | 同一10 SKU、相同输出规格，比较保真度、可用率、实际账单 |
| 是否支持任意平台视频链接 | 对具体平台和链接类型做成功率验证；不对“全网链接”作笼统承诺 |
| 详情页是否稳定支持中文与多屏 | 实测6屏连续风格、长文案、规格表以及逐屏PNG/JPG下载 |
| 爆款模板与自带视频差异 | 分别用站内模板和自带参考视频完成真实成片 |
| 视频编辑是否适用于商品替换 | 通过手持遮挡、透明包装、Logo和快速运动样本 |
| 国内模型的商用、留存及部署地域 | 逐项查供应商正式条款、账号权益与具体服务地域 |
