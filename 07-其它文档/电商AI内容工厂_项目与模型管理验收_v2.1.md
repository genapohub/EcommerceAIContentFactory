# 项目与模型管理验收

日期：2026-09-17。范围仅为本次旁支提出的三项管理功能，不代表主任务的设备授权或真实生成验收结论。

## 已实现

1. 国内模型列表增加删除按钮；已启用模型不可删除。使用页内确认弹窗，删除后同步刷新列表及生成能力状态。
2. 编辑模型的下拉框开放选择。允许同厂商切换并保留密钥；跨厂商切换不复用旧密钥，启用前必须填写新密钥。可恢复任务仍引用该配置时阻止更换模型类型。
3. 左侧商品项目增加重命名和删除图标；窄屏项目选择器旁也提供入口。重命名保留已有资料、方案和素材。删除确认后，在事务中删除项目及关联素材记录、任务记录，再清理素材文件。运行中、排队、待核对任务或正在导入素材会阻止删除。
4. 删除当前项目后选择剩余项目；删除最后一个项目显示空状态，刷新不再自动创建未命名项目，仍可手动新建。

## 新接口

| 方法 | 路径 | 说明 |
|---|---|---|
| PATCH | `/api/v1/projects/:id/name` | 请求 `{ "name": "项目名称" }`，去除首尾空白，1至100字符 |
| DELETE | `/api/v1/projects/:id` | 删除项目及关联数据；返回 `deleted` 和 `cleanupPending` |
| DELETE | `/api/v1/config/models/:id` | 仅未启用且无运行或待核对任务、无连接测试的配置可删除 |

既有 PATCH 模型配置接口支持更换 `templateId`。关联任务限制由后端校验，不能通过直接调用接口绕过。
