# 国内模型列表管理交付说明

日期：2026-09-17。本次仅按用户提供的 CC Switch 截图改造国内模型配置，不执行主任务中的模型付费生成、部署重启或账号配置。

## 已实现

- 模型列表：名称、服务商、能力、模型ID、官方接口地址、密钥是否设置、测试结果、测试时间与延迟。
- 新增与编辑：支持万相文生图、图生图、图生视频，通义视觉Plus/Flash，Vidu视频复刻的独立配置；模型模板限定为当前真实适配器支持的国内接口。
- 逐项启用/禁用。每种能力同一时刻使用一个启用模型，启用同类配置会切换后续任务。
- 搜索名称或模型ID，按生成能力筛选；桌面行式布局，手机自动换行，无横向溢出。
- 连接测试：未测试、测试中、接口连通、失败、待实际验证。百炼使用模型列表接口作免费连通验证，并检查响应结构；不将其视为具体生成权限通过。
- Vidu未核实免费鉴权探测接口，只校验密钥配置并显示待实际验证，不显示虚假的“连接成功”。
- 任务保存模型配置ID；禁用旧模型后，已提交任务仍按原模型查询。运行中任务阻止修改其接入参数，避免串账号；后续新任务受启用状态约束。
- 密钥只留在进程内存，不回显、不入数据库。启用状态和非敏感配置持久化。模型测试状态属于当前服务会话。
- 费用与预算折叠到列表下方，保留原有预算与Vidu计费设置。

## 修改范围

新增 `服务端/模型目录.mjs`、`前端/模型管理.js`、`前端/模型管理.css`、`测试/模型管理.test.mjs`。

已有配置、路由、适配器、报价和任务执行增加模型选择支持；主界面仅增加配置列表容器与入口。若连接到尚未重启的旧服务端，前端保留原配置表单兼容路径，不中断旧服务。

新增接口：

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| POST | `/api/v1/config/models` | 新增配置 |
| PATCH | `/api/v1/config/models/{id}` | 编辑或启停 |
| POST | `/api/v1/config/models/{id}/check` | 连接测试 |
| GET | `/api/v1/config` | 返回models与modelTemplates；不返回密钥 |

配置字段：`name`、`templateId`、`workspaceId`、`apiKey`、`clearKey`、`enabled`。`apiKey`留空表示保留，`clearKey=true`表示清除本配置密钥。模板决定固定国内服务商与接口协议，不支持把任意代理地址冒充官方服务。
