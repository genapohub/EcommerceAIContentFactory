## 执行方式

先在PowerShell切换到验收目录：

```powershell
Set-Location 'C:/Users/OPC/Downloads/WorkSpace/电商AI内容工厂/07-其它文档/界面验收'
```

### 推荐：新版真实登录后的完整复验

```powershell
node './电商AI内容工厂_浏览器验收_v1.0.mjs' --local-login
```

自动启动两个随机端口的本机HTTP服务，运行当前源码；在独立数据库创建 `ui_acceptance` 账号、生成仅驻内存的随机密码，通过页面登录并刷新确认授权，再检查320、375、600、760、900、1100、1440、1920px。服务在结束或失败后关闭，无需外网服务器。

工作台数据、测试账号库、公钥和DPAPI设备身份保存在独立系统临时目录，其路径写入报告。签名私钥和随机密码不写入报告；重复运行创建全新隔离数据。分享验收材料只需截图和JSON报告，不需复制临时运行目录。退出或刷新授权按钮只检查可见性，不点击，不把本次UI验收扩展为授权安全验收。

只复验桌面和手机：

```powershell
node './电商AI内容工厂_浏览器验收_v1.0.mjs' --local-login --widths 375,1440
```

可见浏览器运行：

```powershell
node './电商AI内容工厂_浏览器验收_v1.0.mjs' --local-login --headed --widths 375,1440
```

### 连接已有服务

基础UI复验，无授权成功要求：

```powershell
node './电商AI内容工厂_浏览器验收_v1.0.mjs' --url 'http://127.0.0.1:5188/工作台.html' --widths 375,1440
```

已有服务已真实登录时，强制验证新版授权状态：

```powershell
node './电商AI内容工厂_浏览器验收_v1.0.mjs' --url 'http://127.0.0.1:实际端口/' --require-authorized
```

已有新版服务已配置授权中心、需要人工登录时：

```powershell
node './电商AI内容工厂_浏览器验收_v1.0.mjs' --url 'http://127.0.0.1:实际端口/' --wait-login --require-authorized
```

将 `实际端口` 替换为新版服务端口。脚本显示Chrome后等待人工登录，最长5分钟；账号密码在浏览器输入，不需写入脚本或命令行。旧服务404、未配置授权中心或登录失败时会报告失败，不会自动伪造授权成功。

### 依赖与参数

- Node.js 24及项目原有依赖；本机已安装Google Chrome。`--browser msedge` 可切换到已安装的Edge。
- Playwright查找顺序：`FACTORY_UI_PLAYWRIGHT` 指定目录、项目现有依赖、Codex本机附带运行时。未修改项目package.json、未安装额外依赖。
- 当前可用的包目录：`C:/Users/OPC/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules/playwright`。
- `--project` 可指定代码仓库绝对路径；`--out` 可指定截图输出目录，建议每次使用新目录。默认自动生成带时间戳的目录。
- 输出退出码0表示当前模式通过；1表示失败。检查报告的 `authorized` 与 `result`，仅基础UI通过不代表真实授权成功。

## 验收清单与限制

1. 检查页面及关键容器无横向溢出，375px四个导航同排、无重叠、目标高度至少44px。
2. 已启用模型行是白底；搜索空结果可恢复；新增模型弹窗可打开、输入框有焦点环、Esc可关闭。
3. 新版真实授权成功后，登录表单隐藏、刷新授权及退出按钮显示、生产导航可用，重新加载页面仍为已授权。
4. 授权页、模型页、弹窗、生产页逐宽度生成PNG；未捕获JS异常写入 `pageErrors`，HTTP失败写入 `httpErrors`。
5. 截图禁用有限CSS过渡，以免把导航过渡中间帧当作最终样式。JSON中保留源码哈希、执行时间、浏览器和隔离数据目录。
6. 脚本不会保存模型、启停模型、提交生成或修改已有商品。隔离模式仅在自身临时目录创建一个验收商品和测试授权账号。
7. 本脚本未重放历史的临时DOM压力测试、所有徽标状态和导航内外移动；第一轮相应检查结果是历史证据。当前脚本截图均取实际页面，不注入DOM状态。
8. 登录后UI通过不等于公网部署、账号吊销、换机、租约过期和真实模型生成验收通过；这些仍按各模块测试单独确认。
