# 电商AI内容工厂 部署与操作说明 v2.0

日期：2026-09-17。交付形态：本机单用户 Web 工作台，Node.js 24 + SQLite + 本机素材文件。不是公网多租户部署。

## 结论

新版程序入口为 HTTP 服务的 `/工作台.html`，不再通过双击原静态 HTML 运行。原 `工作台.html / 应用.js / 样式.css / 生成引擎.js` 保留为历史原型，旧浏览器 localStorage 中的记录不会自动成为新版商品项目；原型方案也不会迁移为真实成品。

## 启动

程序目录：`06-项目编码/EcommerceAIContentFactory/`。

1. 当前机器依赖已安装。可在程序目录运行 `启动工作台.ps1`，或者双击 `启动工作台.cmd`。
2. 命令行方式：`node 服务端/启动.mjs`。
3. 打开终端输出的地址，默认 `http://127.0.0.1:5188/工作台.html`。端口占用时自动尝试后续10个端口，不结束其他进程。
4. 新机器安装 Node.js 24 与 pnpm，执行 `pnpm install --frozen-lockfile`。FFmpeg、FFprobe 和 Sharp 通过已锁定依赖安装。不要将 node_modules 跨操作系统复制。

配置 `FACTORY_PORT` 可指定首选端口。服务只绑定 `127.0.0.1`；不要通过反向代理直接暴露到公网。若需团队部署，应另加身份认证、租户隔离、对象存储、队列与限额治理。

## 国内模型配置

| 配置项 | 用途 | 验证边界 |
| --- | --- | --- |
| 百炼 API Key | 万相文生图、图像编辑、图生视频、Qwen视觉分析 | 检查连接会读取模型列表；不保证具体生成模型权限 |
| 百炼业务空间ID | 指向对应北京业务空间 | 可选；留空使用官方默认北京域名 |
| Qwen3 VL Plus / Flash | 商品与参考视频理解 | 分析另按Token计费 |
| Vidu企业 API Key | 参考视频 + 商品图片整片复刻 | 检查配置仅确认已设置密钥；鉴权由真实任务验证 |
| Vidu费率、计费口径确认 | 生成前预估 | 文档未统一明确复刻秒数口径，需核对账号账单 |
| 单批预估上限 | 阻止超预算批次提交 | 不是供应商侧余额锁定；不含未知Token费和另行重试 |

密钥只在服务进程内存保存，接口不返回密钥、数据库不写入密钥、前端不把密钥写入 localStorage。重启服务后需要重新配置，也可自行设置 `DASHSCOPE_API_KEY` 和 `VIDU_API_KEY` 环境变量。不要在聊天、代码仓库或验收报告中记录密钥。

## 商品内容流程

1. 新建商品项目，拍摄或上传商品照片。商品名称、类目、价格、人群、卖点、画面要求均可选。
2. 直接生成，或先执行“提炼卖点”。AI结果出现在任务页，由人工点击“应用分析结果”；不会悄悄覆盖已编辑文案。锁定卖点保留。
3. 选择主图、6屏详情、介绍视频，确认每项费用后提交。
4. 主图支持1～3张；文生图独立输入描述，无需上传商品图。文生图不能保证真实商品外观，真实商品优先用原图生成。
5. 分屏按900×1200输出：商品亮相、核心卖点、使用场景、细节展示、规格与包装、购买须知。逐屏编辑标题、正文、画面要求和来源卖点。
6. 已有配图时，“更新排版”只重新排中文文字，不调用生成模型、不产生模型费。改画面需要重新生成该屏。
7. 视频支持5/10/15秒、生成音频开关和3条脚本变体。提交的是完整生成提示，不保证音频逐字复现脚本；播放检查字幕、口播和商品形态后再发布。

## 参考视频复刻

1. 切到“参考视频复刻”，上传自有商品照片。
2. 粘贴视频直链/公开可读媒体页面，或上传MP4/MOV文件。链接读取会下载并验证实际视频；登录页、反爬页面、没有公开媒体地址的分享页会提示改用上传。
3. 参考片5～180秒，文件不超过100MB；提交前压缩成适合API请求的720宽MP4。过长或压缩后仍过大的视频需裁剪。
4. 可先由Qwen分析钩子、痛点、证明、CTA与镜头；这是独立候选分析，不声称准确转录了全部音频。
5. 使用Vidu官方整片复刻任务，输出9:16、720p。首版不含逐镜头时间轴编辑、精确替换人物、原片无损换商品、自动投放。
6. 当前不是自主实现的“拆镜头→逐镜头生成→后期配音字幕”流水线，该可控方案属于后续迭代。

## 任务与导出

- 并发2个生成任务；每个任务保存商品快照。批次内单项失败不删除其他成品。
- 只有下载成功且文件可解码时才标记完成。该状态表示文件处理完成，不代表画面、口型、音轨、商品事实已人工验收。
- 重复提交同一标识复用任务。已有上游编号继续查询；请求发出但结果不明时标记“待核对”，不会自动再次付费。
- 重新提交失败任务前确认可能产生新费用。查询和下载的重试复用原任务。
- 导出：单张图片、视频、Markdown文案、CSV分镜、全部媒体ZIP。所有详情屏已生成后可导出900×7200长图。
- 详情文案更新后需点“更新排版”，已导出的旧文件不会被追溯替换。

## 数据与维护

`运行数据/内容工厂.sqlite` 保存项目、配置与任务，`运行数据/素材/` 保存输入和成品。备份时先正常结束服务，再复制整个 `运行数据`，不要仅备份SQLite而漏掉素材文件。素材当前不会自动清理。

同一数据目录只运行一个服务进程；不要同时启动两个生产实例处理同一任务队列。更新服务需重启，重启会清空通过页面设置的内存密钥。页面失去会话时刷新并重新配置。
