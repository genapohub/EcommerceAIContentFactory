# 电商AI内容工厂_生成引擎与API配置方案_v1.0

## 结论

当前 MVP 先验证前端内容生产体验。内容生产区生成后直接展示商品主图、介绍视频、分屏详情页三类交付物预览；真实生成能力后续通过国内图文模型、视频模型和视频理解服务接入。

## 国内模型配置

工作台内保留“国内模型配置”页，只配置国内服务商，不提供非国内通用入口。

| 字段 | 说明 |
| --- | --- |
| 国内服务商 | 火山/即梦、阿里云/通义、百度千帆、腾讯混元、智谱、自有国内模型网关 |
| 接口地址 | 国内模型服务 API 地址 |
| 图文模型名称 | 用于商品主图、详情页分屏图、卖点文案和视觉理解 |
| 视频模型名称 | 用于介绍视频、爆款复刻镜头和成片草稿 |
| API Key | 仅用于页面配置草案，不写入本地存储 |
| 单次生成预算 | 用于运营侧成本提醒 |

## 输入输出

| 类型 | 说明 |
| --- | --- |
| 商品输入 | 商品资料、商品实拍原图、生成要求 |
| 爆款参考 | 爆款链接、爆款视频文件、爆款口播/观察 |
| 内容输出 | 商品主图、介绍视频、分屏详情页、详情页模块、短视频脚本、发布前检查 |

## 接入建议

1. 图文模型先接商品主图和详情页分屏图生成。
2. 视频理解先接爆款视频抽帧、字幕 OCR、语音转文字和镜头节奏分析。
3. 视频模型再接商品介绍视频生成和爆款结构复刻。
4. 后端负责 API Key 托管、调用日志、任务状态和成本统计。

## 验收

- 页面不出现非国内通用入口和本地引擎配置。
- 国内模型配置能保存非敏感配置草案。
- API Key 不写入 localStorage。
- 模拟检测不发起外部请求。
- 内容生产区第一屏展示商品主图、介绍视频、分屏详情页。
