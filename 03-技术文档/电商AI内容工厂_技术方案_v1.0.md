# 电商AI内容工厂_技术方案_v1.0

## 结论

MVP 采用静态 Web 架构，代码统一放在 `06-项目编码/EcommerceAIContentFactory/`：`工作台.html` 负责页面结构，`样式.css` 负责科技感控制台样式，`应用.js` 负责交互、生成记录和模型接入草案，`生成引擎.js` 负责内容生成和导出。当前不接后端，后续可把生成引擎替换为 API 调用。

## 数据对象

| 对象 | 说明 |
| --- | --- |
| ProductProfile | 商品名称、类目、价格、目标人群、规格、卖点、素材数量 |
| SellingPointBank | 核心卖点、证明材料、场景、顾虑、禁用表达 |
| ViralVideoAnalysis | 爆款类型、前三秒钩子、节奏、复刻策略 |
| DetailPagePlan | 商详页模块、模块文案、配图建议、卖点来源 |
| VideoCreativePlan | 标题、结构、口播、镜头、字幕、CTA、时长 |
| ComplianceReport | 一致性、风险词、版权边界、素材缺口、补拍建议 |

## 实现方案

1. 表单收集商品信息和爆款参考。
2. 本地生成引擎按类目预设和用户输入提炼卖点库。
3. 根据爆款文案关键词识别结构类型。
4. 由同一卖点库生成商详页模块和短视频脚本，确保一致性。
5. 对绝对化词、素材缺口和复刻边界做发布前检查。
6. 将结果渲染到页面，并支持复制或导出 Markdown。
7. 将每次生成保存为本地记录，记录商品名、类目、时间、风险词数量、详情页模块数和短视频方案数。
8. 在“国内模型配置”页展示火山、阿里云、百度、腾讯、智谱或自有国内模型网关配置；API Key 不落本地存储，不发起外部请求。

## 后续扩展

| 阶段 | 能力 | 说明 |
| --- | --- | --- |
| V1.1 | 接入国内图文模型 | 生成商品主图、详情页分屏图，提高文案质量 |
| V1.2 | 多模态素材理解 | 从商品图和详情页截图提取卖点 |
| V1.3 | 视频拆解 | 从爆款视频中识别镜头、字幕、口播和节奏 |
| V2.0 | 自动成片 | 接入现有短视频生成链路，生成真实视频 |
| V2.1 | 投放反馈 | 回收播放、点击、成交数据，反哺卖点库 |

## 风险边界

- 当前不承诺 AI 自动选品。
- 当前不承诺真实视频画面、口型和音频已经生成或验证。
- 爆款复制只复刻策略，不复制竞品素材和完整文案。
