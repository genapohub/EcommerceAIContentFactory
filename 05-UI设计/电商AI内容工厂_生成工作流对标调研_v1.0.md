## 一、结论摘要

建议保留现有“左侧输入、右侧产出”和“内容生产 / 生成记录 / 国内模型配置”结构，在内容生产区加入两个同级任务入口：**商品内容生成**与**参考视频复刻**。入口按任务区分，底层复用同一份商品资料和素材，避免让运营重复填写。

| 方向 | 建议 | 业务目的 |
| --- | --- | --- |
| 商品内容生成 | 商品图 → 选择主图、分屏商详、介绍视频 → 确认成本 → 生成与编辑 → 图片/MP4导出 | 一个商品素材支持多种产出，各任务独立完成 |
| 参考视频复刻 | 参考视频链接或文件 + 商品素材 → 解析结构 → 镜头确认 → 确认成片成本 → 视频成品 | 在昂贵的生成前确认镜头，减少整片返工 |
| 低门槛录入 | 全部基础字段可选；仅任务真正缺少必要媒体时阻断该任务；草稿始终可保存 | 不因表单完整度限制试用和素材整理 |
| 真实交付 | 将方案、预览、真实文件分开标识；单镜头重试、逐屏编辑、按产物导出 | 避免把脚本或示意图误当可发布成品 |
| 配置边界 | 只保留国内服务商与自有国内模型网关，不提供本地引擎、国外供应商入口 | 延续现有配置范围 |

**关键差异：**现有 PRD 明确首版优先验证内容策略和脚本，运行说明明确尚未接入真实模型、视频解析与自动成片。本报告中的图片/MP4生成、镜头编辑和任务队列是下一阶段建议，不代表当前功能已经可用。PRD 的“10 分钟内导出内容方案”是产品目标，不能扩展为真实视频生成时长承诺。

**竞品边界：**PicCopilot已取得的官方说明支持“商品图片+视频模板”的路径，尚未证实任意自带参考视频链接/文件；本项目的自带参考视频流程来自用户明确需求。官方详情页帮助描述文案/排版编辑与高分辨率素材导出，但分屏导出尚未核实，本报告的分屏导出属于本项目设计建议。

## 四、推荐交互方案

本节及后续流程、状态、文案与验收均为**设计建议**。

参考视频链接/文件是本项目已明确的需求，不能以PicCopilot的模板功能为已验证实现依据。商品图流程保持一张图可开始；多角度图片可补充细节，不强制新增输入负担。模板可作为后续可选快捷来源，不挤占本轮双流程范围。

### 4.1 工作台布局

保持“内容生产 / 生成记录 / 国内模型配置”三页签。在内容生产区顶部设置“商品内容生成 / 参考视频复刻”分段控件，默认商品内容生成。切换任务保留已填资料、素材和草稿，不自动发起付费操作。

桌面左栏依次放当前任务媒体、可选商品资料、生成要求；右侧先显示任务产物与镜头/分屏工作区，再显示原有商品档案、脚本、风险检查。现有长表单按“商品信息、卖点与规格、参考补充”折叠分组；每组控制在约4项，缺失项不渲染红色报错。

右侧底部或操作区常驻本次选择、预估成本、主按钮。生成记录保留商品、任务类型、产物数量、状态、版本和时间；点击历史版本只载入对应结果，不覆盖当前未保存草稿。窄屏改为“素材 / 编辑 / 结果”视图切换，成本与主操作保持可见且不遮挡输入。

### 4.2 全量字段保留与可选规则

| 现有字段或输入 | 建议处理 | 缺失时行为 |
| --- | --- | --- |
| 商品名称 `name` | 可选，保留 | 草稿使用“未命名商品”；不伪造品牌或商品名 |

| 规格与事实 `specs` | 可选，保留 | 不推断容量、证书、材质、疗效、售后政策等事实 |
| 核心卖点 `claims` | 可选，保留 | 可给候选表达；未经证实的性能主张进入待确认清单 |

基础字段全部可选。媒体规则按具体任务检验，不能给整个商品表单统一加必填标记。后续若国内服务支持其他可用商品素材，校验以实际能力为准，不额外强制用户上传同一用途的图片。

保存草稿不要求媒体、模型配置、预算或镜头确认。未填内容保持为空，生成建议不得覆盖用户原值；用户接受后才写回。刷新恢复时若浏览器不能恢复文件本体，显示“素材需重新选择”，保留其余草稿内容。

### 4.3 流程A：商品图生成商品内容

1. 上传商品图，显示缩略图、替换、移除、上传状态和失败原因；以服务实际限制校验格式/大小，不虚构固定限制。
2. 选择主图、分屏商详、介绍视频，可单选或多选。比例使用分段控件，数量/时长使用步进器或输入框；默认值明确可见。
3. 展示各任务输入条件、预估成本及合计。用“生成所选内容”作为主操作；仍保留独立的“生成方案”和“保存草稿”。
4. 提交前列明可生成和缺素材的任务，由用户明确提交可生成项；受阻任务保留待输入状态，不能被悄悄跳过或拖累其他任务。
5. 分任务显示排队、生成和结果。主图成功后立即可查看/导出，不等待视频任务结束。
6. 分屏商详逐屏编辑；介绍视频可进入镜头确认/调整。替换素材或改提示词后仅重生成受影响产物，并再次显示该次费用。
7. 图片按单张、所选分屏或完整长图导出；真实视频成片完成后导出MP4。Markdown方案导出继续保留。

### 4.4 流程B：参考视频复刻

1. 提供参考视频链接或文件，并提供商品素材。链接和文件同时存在时明确选择本次参考源；不重复解析、不合并成未经确认的参考。
2. 解析前显示解析费用。可访问且受支持的链接才进入解析；需要登录、链接失效、不受支持时提示“无法读取该链接，请上传视频文件”，保留来源地址和其他输入。
3. 解析结果按镜头列表展示参考时间段、镜头功能、节奏、钩子、字幕/口播和商品素材映射。系统推断标记“待确认”；未识别内容留空，不编造观察。
4. 镜头确认区采用左侧镜头缩略列表、中间当前镜头、右侧属性。支持增删/排序、素材替换、口播字幕修改、时长修改和单镜头确认；拖动排序同时提供可键盘操作的上移/下移。
5. 只复用参考的结构、节奏和表达策略。保留现有发布前检查，不默认复制竞争商品画面、人物、商标、未经证实的卖点和完整文案。
6. 展示总时长、镜头数、解析已发生费用、镜头生成与合成预估费用。缺必要素材的镜头内定位问题，其他已确认镜头可保留；用户点击“确认镜头并生成视频”后提交。
7. 镜头并行或顺序执行由服务能力决定，界面显示各镜头实际状态。单镜头失败时只重试该镜头；重试成功后提示重新合成，说明合成是否另计费用。
8. 全部目标镜头可用且合成/转码完成、文件可播放下载后显示“成品就绪”。仅有分镜脚本、静态封面、视频草稿或部分片段时，不显示“视频已完成”。

## 五、任务状态与异常交互

### 5.1 七种完整状态

状态同时作用于单个产物/镜头和任务汇总，草稿保存状态独立存在，不与生成状态混为一谈。

| 状态 | 判断条件 | 界面反馈 | 可执行动作 |
| --- | --- | --- | --- |
| 待输入 | 当前任务缺少必要媒体，或尚未选择产物 | 直接指向缺少素材的位置；基础字段不报必填错 | 上传/替换、切换目标、保存草稿、生成文字方案 |
| 待生成 | 输入达到任务要求，但还未提交 | 展示产物设置、成本、必要的镜头确认；配置未就绪则显示独立阻断原因 | 编辑、保存；满足配置和确认条件后提交 |
| 排队 | 服务已确认接单但未开始处理 | 显示任务编号、提交时间；只有真实返回时才显示队列位置 | 查看草稿、离开页面后回来；仅服务支持时允许取消 |
| 生成中 | 服务正在解析、生成镜头或合成 | 展示真实阶段及已完成镜头数；没有真实进度时不编造百分比 | 查看已有结果，编辑下一版草稿，保留当前执行参数 |
| 部分成功 | 本次执行已结束，至少一项成功且至少一项失败/受阻 | 成功项与失败项分别列出，原因落到单项 | 导出成功图片、重试失败镜头、补素材；完整MP4需成片条件达成 |
| 失败 | 本次执行结束且没有可用的目标产物 | 显示原因、已产生费用或待核算状态、下一步动作 | 修改配置/素材、再次报价后重试；保留输入 |
| 成品就绪 | 本次目标产物均完成，真实文件通过可访问与基本可用性检查 | 显示格式、尺寸/时长、版本、费用状态与导出 | 查看、导出、创建新版本 |

汇总优先级：仍有任务运行时显示“生成中（已完成X/Y）”；仅在等待时显示排队；全部结束后再判部分成功、失败或成品就绪。混合批次提交时纳入清单但缺素材的项目保留“待输入”，批次最终可以是部分成功；明确未选中的项目不计入分母。

典型路径：待输入 → 待生成 → 排队 → 生成中 → 成品就绪/部分成功/失败。失败重试返回待生成，重新确认费用后提交。方案完成采用独立标签“方案已生成”，不借用真实媒体的“成品就绪”。

### 5.2 容易误判的边界

| 情况 | 建议处理 |
| --- | --- |
| 连点生成或网络返回慢 | 当前提交按钮显示提交中并防重复提交；超时先查询原任务，未确认失败前不新建付费任务 |
| 刷新/退出后回来 | 按原任务恢复查询；未取得状态时显示“状态同步中”，不直接判生成失败 |
| 用户生成中修改资料 | 当前任务使用提交时版本；修改存入新草稿，完成后不覆盖新输入 |
| 配额不足/模型不可用 | 只阻断依赖该服务的任务；主图能力可用时不被视频配置问题阻断 |
| 个别镜头失败 | 成功镜头不重跑；重试项显示新增预估费用和受影响的合成步骤 |
| 文件导出失败 | 显示“导出失败，重新下载”；不自动重生成已成功产物，不重复计生成费 |
| 取消/中断 | 仅收到服务确认后标记“已取消”的补充状态；展示实际完成项与计费，保留草稿 |
| 文件链接过期 | 标记下载链接失效；先刷新可用链接，无法恢复再说明重生成条件与费用 |

## 六、编辑、成本与导出规范

### 6.1 分屏与镜头编辑

分屏商详使用缩略图列表加当前屏编辑区，保留首屏、卖点、场景、证明、对比、FAQ、下单理由等既有业务模块。逐屏支持修改文案、替换商品素材、调整顺序、删除和单屏重生成，保留来源卖点与版本。

图片若已是文字合成后的位图，修改文案应标记“需要重新生成该屏”，不能承诺原位编辑文字。若未来采用可编辑文字层，再提供直接排版能力。每次单屏生成保留上一版，允许用户比较后选择。

镜头编辑区分别标注“参考视频”“商品素材”“生成片段”，避免把参考画面当输出。修改已完成镜头后标记“已修改，待重新生成”；旧片段保留为上一版，最终MP4标记“需重新合成”，不静默替换。

### 6.2 生成前费用与时间

- 首次生成、解析参考、单镜头重试、单屏重生成、重新合成前，均显示本次涉及的任务和预估成本。
- 报价按图片数、镜头数/时长、模型及合成步骤拆分，区分预估、已发生、待核算与最终费用；沿用单次生成预算作为提醒阈值。
- 若无可靠报价，显示“暂无法估算”，不写0元。需要付费时取得可核对报价或明确可执行费用上限后再提交，草稿和方案编辑不受影响。
- 超出预算时用户可减少产物、缩短时长或调整预算；不默认自动换模型、降规格或重试全部镜头。
- 只有实际历史统计或服务返回才能展示预计等待区间，并标记为估计；缺乏数据只显示当前阶段。不照搬竞品“1分钟”“瞬间”等宣传时长。

### 6.3 预览与成品的明确界线

| 对象 | 可用标签 | 允许的导出 |
| --- | --- | --- |
| 输入商品图/参考视频 | 原始素材/参考视频 | 原文件下载如有，不能称为AI生成成品 |
| 脚本、提示词、分镜规划 | 方案已生成 | Markdown方案 |
| 静态示意、无成片文件的播放器外观 | 效果预览/分镜预览 | 如允许导出示意图，明确标为预览，不出现MP4下载 |
| 真实完成的商品图/分屏图 | 图片成品就绪 | 实际支持的PNG/JPG；分屏可单张、所选图片包或拼接长图 |
| 已完成且可播放下载的视频 | 视频成品就绪 | MP4，显示真实分辨率、时长和版本 |

图片导出需检查拼接顺序、文字裁切、尺寸和背景；MP4需检查容器/编码可播放、镜头完整、音画与字幕。下载按钮只有文件存在时启用。若存在水印或分辨率限制，生成前展示，不能下载时才揭示。

## 七、国内模型配置与视觉建议

### 7.1 配置交互

沿用火山/即梦、阿里云/通义、百度千帆、腾讯混元、智谱、自有国内模型网关。竞品选取只用于交互研究，Creatify和Topview不进入供应商配置。不给本地引擎或国外供应商增加入口。

继续保留接口地址、图文模型、视频模型、API Key和预算字段。以文字/图像生成、视频理解、视频生成为能力维度标明“未配置 / 未验证 / 可用 / 异常”；供应商出现在列表中不等于支持全部能力。参数仍是草案时标“配置草案”，模拟检测不得显示“连接成功”。

API Key不在历史记录、导出文件或localStorage中保存。后续正式接入的凭证托管由技术方案处理；界面只展示掩码和连接结果。业务工作区只显示当前任务能否生成及必要修复入口，详细参数留在配置页。

### 7.2 视觉与可用性

- 延续现有深色控制台、科技绿主操作，青色辅助、琥珀警告、珊瑚风险；中性色为主，语义色配文字，不把整屏染成同一种强调色。
- 延续Lucide线性图标，行内16px、按钮20px、独立24px；不用emoji。替换、删除、下载、重试使用图标与可访问名称，陌生图标提供提示。
- 主操作随阶段变化为“生成所选内容”“解析参考视频”“确认镜头并生成视频”；次操作为保存草稿和编辑，避免多个高亮生成按钮竞争。
- 字体建议统一中文Noto Sans SC、拉丁Inter，采用Token引用；正文14/16px、区域标题18/20px、页面标题24px，字距0。不因视口宽度任意缩放字号。
- 复用并补齐背景、表面、文字、弱文字、边框、强调、成功、警告、错误、字体、间距、圆角、焦点、动效Token；本次不新增CSS或设计Token文件。
- 圆角不超过8px；区域以分隔线与固定栅格组织，不做卡片套卡片。无紫粉渐变、发光毛玻璃组合、装饰性Hero或空泛宣传文案。
- 缩略图区固定比例，工具栏尺寸稳定；长商品名换行，不挤压按钮；悬浮时不改变布局。
- 键盘可操作上传、任务选择、排序和重试，焦点可见；状态变更可被辅助技术读取；动效控制在约150ms并支持减少动态效果。
