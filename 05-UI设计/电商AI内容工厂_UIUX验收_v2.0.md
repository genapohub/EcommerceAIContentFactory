# 电商AI内容工厂 UI/UX验收 v2.0

2026-09-17。按 mvp-expert-team 的设计师与QA视角顺序复核，不冒充独立真人设计师签字。

## 设计决策

Product工具界面；信息密度优先。白灰基底、绿色主操作、蓝色参考任务、红色失败，统一Lucide图标。侧栏只保留内容生产、生成任务、国内模型；不设置营销首页。基础资料选填，媒体条件在对应生成任务内检查。

主要交互为“商品素材 / 参考视频 → 费用确认 → 成品预览 → 编辑或导出”。图片与视频占内容区，脚本与卖点位于独立标签。桌面素材栏和成品区分别滚动，生成操作保持可见；窄屏垂直排列并提供独立项目选择器。

## 状态覆盖

| 状态 | 可见反馈与恢复路径 |
| --- | --- |
| 空项目 | 原始照片入口，空成品计数，无伪造示例 |
| 缺少模型/素材 | 明确缺失项，确认提交按钮禁用 |
| 生成中 | 任务计数、任务列表、独立状态 |
| 部分成功 | 成功文件保留，失败任务逐项重试 |
| 结果不确定 | 待核对状态；继续查询或明确确认重新提交 |
| 已完成 | 图片/视频直接预览、文件下载 |
| 未保存 | 顶栏提示，切换项目前保存，离开页面确认 |
| 服务中断 | 本机连接状态提示；刷新后获取新会话 |

## 本轮发现与修复

1. 中文静态资源挂载路径导致资源404：改为ASCII路由前缀，文件名仍保留中文，并加入HTTP测试。
2. 首屏生成按钮偏低：固定工作区高度、分栏滚动，压缩工具栏和底部操作间距。
3. 窄屏侧栏隐藏后无法创建/切换项目：补充紧凑项目选择器与新建入口。
4. 自动轮询重绘导致播放器中断：仅在数据变化时更新成品区。
5. 切换标签残留上个面板滚动位置：切换时重置成品区滚动。
6. 长文案排版被截断：按可用尺寸自动缩小字体，测试500字正文完整保留。
7. 移动导航只有图标时缺少可访问名称：显式添加aria-label与title。
