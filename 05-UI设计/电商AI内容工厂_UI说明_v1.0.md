# 电商AI内容工厂_UI说明_v1.0

## 结论

界面采用科技感工作台布局，左侧录入，右侧输出。右侧调整为“内容生产 / 生成记录 / 国内模型配置”页签，既能跑业务主流程，也能回看历史方案，还能配置后续国内图文和视频模型。视觉风格偏数据控制台，不做营销落地页，不使用大面积紫粉渐变和模板化 Hero。

## 设计原则

| 原则 | 说明 |
| --- | --- |
| 高密度但不拥挤 | 适合运营反复录入 SKU 和比对输出 |
| 核心操作优先 | “生成方案”是页面最高权重操作，视觉上高于填样例、复制和导出 |
| 先结果后解释 | 输出模块按业务流程分组，方便复制修改 |
| 可追溯 | 每个详情页模块标记来源卖点 |
| 风险前置 | 发布前检查单独成区，避免直接发布高风险内容 |

## 页面结构

1. 顶部：产品定位和北极星指标。
2. 左侧：商品资料、商品实拍原图、AI 生成目标、生成要求、爆款参考、爆款视频文件、生成操作。
3. 右侧内容生产页：导出工具、空状态、商品主图、介绍视频、分屏详情页和生成结果。
4. 右侧生成记录页：生成摘要、商品历史、风险数量、载入历史结果。
5. 右侧国内模型配置页：国内服务商选择、接口地址、图文模型、视频模型、API Key、预算和模拟检测状态。
6. 结果区：商品转化档案、爆款结构卡、素材复制工作台、详情页模块、短视频方案、发布前检查。

## 视觉规范

- 主色：科技绿色，用于主按钮和关键标签。
- 辅色：青色、琥珀色、珊瑚色，用于导航、提示和风险信息。
- 背景：深色控制台，提高信息密度和产品科技感。
- 圆角：控制在 8px 以内。
- 图标：按钮使用统一线性图标，避免使用表情符号作功能图标。

## 本轮布局优化

- 顶部标题、说明文案和指标区高度已压缩，减少首屏占用。
- 左侧表单字段、上传区和操作区间距已收紧，适合连续录入多个 SKU。
- 右侧工作台、结果卡片和空状态留白已减少，核心输出更早进入视野。
- “生成方案”按钮强化为主操作样式，使用更高按钮、更亮描边和轻投影承接核心路径。

## 素材工作台补充

- 素材入口从“上传成品主图/视频/分屏图”调整为“上传一张商品实拍原图”。
- 生成结果新增“素材复制工作台”，用于说明商品原图如何生成主图、视频和详情页分屏图，以及爆款参考如何映射到短视频复制方案。
- 当前不做真实视频解析，界面文案明确只做素材记录、结构复刻建议和后续模型接入预留。
- 内容生产区生成后优先展示商品主图、介绍视频、分屏详情页三类交付物预览。
- 模型配置区已去掉非国内通用入口，只保留国内模型服务商配置。
