  - frontend-dev-guide：待命（等 PRD 定稿后接 UI 实现）

待交接上下文：
  - [product → frontend] PRD v2.0 完成后通知 frontend-dev-guide 进入 UI 还原
  - [frontend → qa] UI 还原完成后通知 qa-testing-guide 跑视觉走查

  - 【示例】主色 #3B82F6，圆角 8px，间距 16px 基线
