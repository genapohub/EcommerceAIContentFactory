# 电商 AI 内容工厂运行说明

## 结论

当前版本是前端静态 MVP，重点验证商品内容生产流程和国内模型接入配置。打开 `工作台.html` 即可试用商品转化内容生成流程：上传一张商品实拍原图，内容生产区会直接展示商品主图、介绍视频和分屏详情页预览；爆款视频可通过链接或文件作为复制参考。

## 使用步骤

1. 打开 `电商AI内容工厂/06-项目编码/EcommerceAIContentFactory/工作台.html`。
2. 点击“填入样例”快速查看完整输出，或手动填写商品资料和爆款参考。
3. 上传商品实拍原图，填写生成要求；也可以填写爆款链接或上传爆款视频文件。
4. 点击“生成方案”，先查看商品主图、介绍视频、分屏详情页，再查看商品转化档案、爆款结构卡、详情页模块、短视频脚本和发布前检查。
5. 点击“复制 Markdown”或“导出方案”，将结果交给运营继续微调。
6. 切换到“生成记录”，查看每次生成留下的商品、时间、风险、素材和方案数量。
7. 切换到“国内模型配置”，填写火山、阿里云、百度、腾讯、智谱或自有国内模型网关参数。

## 当前边界

- 当前页面只做前端预览和配置草案，真实大模型、多模态视频理解、自动成片、自动投放尚未接入。
- 爆款复制只复刻结构、节奏、镜头功能和表达策略，不复制竞品画面、人物、商标和完整文案。
- 商品实拍原图当前只生成主图、视频、详情页分屏图的生产方案和提示词，不直接产出真实图片/视频文件。
- 爆款视频链接和视频文件当前只做来源记录、素材统计和复刻建议，不会自动抓取链接内容，也不会解析视频画面、字幕和音频。
- API Key 字段只用于页面配置草案，保存时不会写入本地存储，也不会发起外部请求。
- 生成记录保存在当前浏览器本地，换浏览器或清理站点数据后不会自动保留。
